# Tennis Count 2026

[English README](README.md)

Android-приложение для автоматического ведения счёта теннисного матча. Приложение слушает
микрофон, распознаёт счёт, объявляемый игроками вслух («пятнадцать-ноль», «ровно»,
«больше», «гейм»…), и само ведёт полный счёт: очки, геймы, сеты. Распознавание работает
полностью офлайн (Vosk, русская модель) — интернет на корте не нужен.

## Возможности

- Офлайн-распознавание русской речи (Vosk), грамматика ограничена словами счёта —
  это повышает точность и защищает от посторонних разговоров.
- Полные правила любительского тенниса: deuce/advantage, сет до преимущества в 2 гейма
  (без тай-брейка), число сетов не ограничено — матч завершается вручную.
- Автоматическая смена подающего каждый гейм; порядок чисел в объявлении —
  сначала очки подающего.
- Проверка согласованности объявлений: счёт применяется, только если он ровно на один
  розыгрыш больше текущего (отсекаются BACKWARD / DUPLICATE / SKIP). Проверку можно
  отключить в настройках на табло.
- Ручная корректировка: +очко игроку, отмена последнего действия («отмена» — и голосом),
  редактирование счёта в гейме и геймов в сете.
- Звуковые сигналы (не глядя на экран): короткий beep — команда принята, низкий двойной —
  отклонена, звонок — гейм засчитан, тройной звонок — завершён сет.
- Авто-озвучка (TTS): счёт по геймам в конце гейма, «сет-поинт», итог сета —
  каждый элемент включается/выключается в настройках. Команда «сколько» —
  озвучить текущий счёт гейма.
- Прослушивание при выключенном/заблокированном экране (foreground service
  с микрофоном), пауза без потери счёта, уведомление со счётом и кнопками Пауза/Стоп.
- Счёт текущего матча, имена игроков и настройки переживают перезапуск приложения.
- История завершённых матчей (Room), сохранение по кнопке «Завершить матч».

## Голосовые команды

| Команда | Действие |
|---|---|
| «пятнадцать ноль», «тридцать пятнадцать», «15-0»… | Объявление счёта (сначала очки подающего) |
| «пятнадцать» (одно число) | Сокращение «15-0» |
| «ровно» | Deuce (40-40) |
| «больше» / «меньше» | Advantage подающего / принимающего |
| «гейм» | Засчитать гейм (победитель определяется по счёту) |
| «сколько» | Озвучить текущий счёт гейма |
| «отмена» / «отмени» | Отменить последнее действие |

## Стек

- Kotlin, Jetpack Compose (Material 3, тёмная тема), MVVM, без DI-фреймворка.
- ASR: Vosk Android (`com.alphacephei:vosk-android:0.3.75`), русская small-модель
  (~45 МБ, скачивается при первом запуске).
- БД: Room (история матчей). Тесты: JUnit (ядро счёта и парсер).
- minSdk 29 (Android 10), targetSdk 36.

## Сборка и тесты

```bat
gradlew.bat :app:assembleDebug       :: сборка APK
gradlew.bat :app:testDebugUnitTest   :: unit-тесты ядра счёта и парсера
```

Требования: JDK 17, Android SDK с платформой android-36 (путь — в `local.properties`).
Подробности сборочного окружения — в [AGENTS.md](AGENTS.md).

## Структура проекта

- `app/.../score/` — чистое Kotlin-ядро правил тенниса (`MatchEngine`, `GameState`,
  `SetState`, `MatchSummary`, `ScoreSpeech`, `MatchStateCodec`), без Android-зависимостей.
- `app/.../speech/` — Vosk: загрузка модели (`ModelManager`), распознаватель
  (`VoskRecognizer`), парсер объявлений (`ScoreParser`, чистый Kotlin).
- `app/.../service/` — foreground service прослушивания (`ListeningService`) и
  синглтон-контроллер (`ListeningController`).
- `app/.../ui/` — Compose-экраны (настройка матча, табло, история), `MatchViewModel`,
  звуковые сигналы (`SignalPlayer`).
- `app/.../data/` — Room, история завершённых матчей.
- `app/src/test/...` — unit-тесты ядра счёта и парсера.

Полное задание и статус этапов разработки (M1–M5) — в [task.md](task.md).
